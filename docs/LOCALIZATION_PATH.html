Энэ сургалтын зорилго бол algorithm нэр цээжлэх бус, sensor хэмжилтээс state estimate хэрхэн үүсдэг, ямар таамаглалтай, юу ажиглагдахгүй үлддэг, ямар алдаанд failure болдгийг ойлгох.

1. What you should be able to explain

  • Point, vector, coordinate frame, SO(3)/SE(3), Jacobian болон covariance-ийн утга, нэгж.
  • RGB pixel ray, axial depth, Euclidean range, LiDAR point болон IMU specific force-ийн ялгаа.
  • Intrinsics, extrinsics, sensor clock offset, point time болон exposure convention.
  • IMU propagation, motion compensation, LiDAR point-to-plane residual, visual patch residual болон shared state update.
  • Calibration, degeneracy, low texture, motion blur, reflective surfaces, synchronization болон compute latency-гаас үүсэх failure.
  • Official FAST-LIVO2 source code-ийн estimator/map orchestration-ийг paper-ийн equation-тай холбох.

Official FAST-LIVO2 үндсэн sensor topics нь image, LiDAR, IMU. Depth stream ашиглавал measurement model, uncertainty, frame/time болон correlation-ийг тусад нь зохион байгуулна. Depth cloud-ийг дурын LiDAR driver input-тэй шууд адилтгаж болохгүй.

4. Read the actual source

Доорх code-reading order нь official upstream revision 0d2c0346107b75b59934975adec9a6eeeb913c64-д тулгуурласан. Online source өөрчлөгдөж болох тул version-оо тэмдэглэ.

  1. config/avia.yaml: image/LiDAR/IMU topics, extrinsics, time offsets, uncertainty-related settings. Sample rig-ийн numbers-ийг өөр sensor rig рүү copy хийхгүй.
  2. include/common_lib.h, StatesGroup: rotation, position, inverse exposure, velocity, gyro/acc biases, gravity; error injection болон covariance. Inspected code-ийн state 19-dimensional perturbation-тай, generic 15-state IMU filter-тэй ялгаатай.
  3. src/LIVMapper.cpp: synchronization, processImu, stateEstimationAndMapping, handleLIO, handleVIO. Sensor event order ба timestamps-ийг trace хий.
  4. src/IMU_Processing.cpp: initialization, propagation, UndistortPcl, Process2. Gravity/bias, dt, per-point compensation-ийг frame diagrams-тай холбо.
  5. src/voxel_map.cpp: StateEstimation, residual construction, plane geometry, iterative Kalman correction, map update.
  6. src/vio.cpp: map retrieval, plane/affine warp, patches, projection Jacobian, computeJacobianAndUpdateEKF, updateState, inverse exposure scaled residual, reference/map updates.

Source-reading worksheet: function бүрд inputs → frame/time → predicted measurement → residual sign/units → Jacobian → covariance → state injection → map mutation гэсэн мөр бөглө. Real code-ийг pedagogical diagram-тай нэг нэгээр нь тааруул.

5. Hands-on experiments

  1. Rig specification: sensor model, driver, rate, timestamp origin, point time units, frame axes, depth units, field of view болон calibration files-ийг бүртгэ.
  2. Stationary test: IMU gravity norm/bias, sensor noise, timestamp monotonicity, image exposure, invalid depth болон LiDAR points-ийг шалга.
  3. Motion synchronization test: slow/fast rotations дээр camera–LiDAR overlay, wall sharpness болон deskew error-ийг харьцуул. Time offset-ийг static scene data-аар дангаар дүгнэхгүй.
  4. Calibration test: held-out poses/image borders дээр overlay/reprojection residual, depth/range consistency болон transform direction-ийг батал.
  5. Bag replay: official example dataset дээр upstream algorithm ажиллуулж topics, states, residual behavior болон map output-ийг trace хий.
  6. Ablations: normal conditions → low visual texture → degenerate LiDAR geometry → motion blur → deliberate clock/calibration error. Sensors ямар failure-г complement хийж байгааг тайлбарла.
  7. Application evaluation: robot trajectory-оос гадна target XYZ/yaw, alignment conventions, latency, failure rate болон uncertainty calibration-г хэмж.

Эдгээрийг зөвхөн өөрийн authorized rig/data дээр хийнэ. Энэ website real hardware-г удирдахгүй; browser лабораториуд нь equation болон failure intuition-ийг тайлбарлах deterministic simplified models.

6. Evaluate honestly

  • ATE/RPE: ground truth frame, timestamp alignment, trajectory association, SE(3) alignment convention, units болон missing pose policy-оо тэмдэглэ.
  • Metric task accuracy: target XYZ, orientation/yaw error; 2 cm шаардлага бол 2.5 cm error-г “good trajectory” гэдгээр зөвтгөхгүй.
  • Estimator consistency: innovation/residual distribution, covariance, outlier handling, repeated-map correlations.
  • Runtime: end-to-end latency, sensor backlog, memory, dropped frames/points, deterministic replay configuration.
  • Failure report: “drift” гэж ганц үгээр бус sensor conditions, geometry, calibration/time, uncertainty болон observability hypothesis-оор тайлбарла.

7. What this course does and does not execute

12 шинэ лаборатори нь vector/matrix transforms, finite differences, seeded noise, line optimization, IMU bias approximation, pinhole projection, 2D exact deskew, scalar Gaussian fusion, point-to-plane residual болон 1D direct photometric loss-ийг бодитоор тооцно. Full 3D FAST-LIVO2 estimator, real sensor input, dense mapping болон ROS execution browser дотор ажиллахгүй.

Inspected official upstream нь ROS1/catkin. ROS2 Jazzy дээр integration хийх бол port, drivers, message/time conventions, launch/config болон validation-ийг тусдаа инженерийн task болгон хийнэ.
