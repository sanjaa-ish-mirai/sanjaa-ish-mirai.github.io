01 / 08 · PHYSICS → IMAGE

Зургийн intensity хаанаас үүсдэг вэ?

Камер ямар нэг “объект”-ийг шууд хадгалдаггүй. Камерын мэдрэгч тодорхой хугацаанд хүрч ирсэн гэрлийн энерги-ийг фотоэлектрон болон цахилгаан сигнал болгон хэмждэг. Ижил объектын RAW pixel утга гэрэлтүүлэг, гадаргуугийн тусгал, линз, exposure болон sensor gain-аас шалтгаалж өөрчлөгдөнө.

Энгийн нэг сувагт image formation model:

I[m,n] = Qb { g · ∬ Amn(x,y) · (h ∗ L)(x,y) dxdy + η }L: image-plane light intensity (optics-ийн дараах хэмжилтийн оронгийн оролт) · h: point-spread function · A: pixel aperture · g: gain · η: noise · Q: quantization

Энэ нэг томьёонд pixel үүсэх хамгийн чухал үе шатууд орсон. h ∗ L нь оптикийн blur, интеграл нь pixel тодорхой талбайн гэрлийг нэгтгэх, η нь хэмжилтийн алдаа, Q нь тасралтгүй analog хэмжилтийг хязгаарлагдмал integer түвшин болгохыг дүрсэлнэ.

ЯАГААД? — Нэг 3D цэг үргэлж нэг pixel байдаггүй

Бодит optics-д point-spread function (PSF) байдаг учир нэг 3D point-ын гэрэл хөрш pixel-үүдэд тархана. Иймээс “high resolution = бүх зүйлийг ялгана” гэдэг дүгнэлт худал; линзний blur, sensor size болон motion blur мөн хязгаар тогтооно.

ГҮНЗГИЙ ОНОЛ · Radiometry vs Geometry

3D world point → image-plane irradiance → electron count

Геометр нь 3D цэг sensor-ийн аль байрлалд буухыг шийднэ. Radiometry нь sensor дээр хэдий хэмжээний гэрэл ирэхийг шийднэ. Surface radiance L (W·sr⁻¹·m⁻²) ба sensor irradiance E (W·m⁻²) нь нэг ижил физик хэмжигдэхүүн биш. Линзийн aperture, focal length, cos⁴ falloff, optical transmission зэрэг нь camera-plane irradiance-д нөлөөлнө.

Ne ≈ ηQE · (E · Apixel · t) / (h c / λ)
I[m,n] = Qb( gain · min(Ne + noise, full-well) )Энд monochromatic light болон simplified linear RAW sensor гэж үзсэн. E: W/m², A: m², t: s, hc/λ: photon energy J, ηQE: quantum efficiency.

Exposure хугацааг 2× өсгөвөл expected electron count ойролцоогоор 2× болно (saturation-гүй үед). Гэвч хөдөлж буй camera-д exposure ихсэхэд motion blur нэмэгдэнэ: temporal integration-ийг мартаж болохгүй.

Lab 00 — PSF / optical blur: Нэг point яагаад тархдаг вэ?

Gaussian PSF бол бодит линзийн хялбарчилсан загвар. σ-ийг ихэсгээд ганц цэг болон нарийн хээ зэрэг хэрхэн бүдгэрч байгааг хар. Spatial frequency-г нэмэхэд blur-ийн нөлөө яагаад хүчтэй болдгийг MTF-аар тооцно.

A · Ideal optical image
B · Image blurred by PSF
C · Point-spread profile (normalized Gaussian)
Gaussian FWHM4.24 px
Stripe contrast retained (MTF)0%
PSFσ(x) = 1/(√(2π)σ) · exp(−x²/(2σ²))
MTF(ν) = exp(−2π²σ²ν²) , ν = f/WW=160 pixel загварын өргөн. σ=0 үед impulse/no blur. MTF нь тухайн sine pattern-ийн contrast ямар хэмжээгээр хадгалагдахыг харуулна.
Яагаад энэ нь feature matching-д хамаатай вэ?

PSF томроход жижиг хэмжээний texture / corner-ийн gradient сулрана. Үүний улмаас descriptor-ийн ялгарал болон subpixel localization муудаж болно. Anti-alias blur нь давхар өндөр frequency-ийн хуурамч мэдээллийг багасгадаг — деталь хадгалах vs aliasing дарах trade-off бий.

Геометрийн талаас

3D цэг хаана проекцлогдохыг camera intrinsics/extrinsics тогтооно. Үүнийг Week 2-т математик аргаар гаргана.

Фотометрийн талаас

Тухайн цэгийн орчмын pixel ямар утгатай болохыг гэрэл, гадаргуу, optics, sensor pipeline тогтооно.

Robotics connection: Visual Odometry-д brightness constancy assumption хэрэглэхэд exposure болон illumination өөрчлөгдвөл яг нэг физик feature хоёр frame-д өөр intensity-тай болж болно. Тиймээс camera response, gain, exposure нь зөвхөн зураг “гоё” эсэх биш, motion estimation-ийн тогтвортой байдалтай холбоотой.

02 / 08 · SAMPLING THEOREM

Sampling ба aliasing: Нарийн судал яагаад буруу харагддаг вэ?

Тасралтгүй scene-д давтагдах pattern байж болно. Камер түүнийг хязгаартай тооны sample буюу pixel болгон хэмжинэ. Sample-ийн тоо хангалтгүй байхад өндөр frequency бага frequency шиг андуурагдах үзэгдлийг aliasing гэдэг.

L(x) = 0.5 + 0.45 cos(2π f x + φ),   0 ≤ x < 1
xn = (n + 0.5) / N;   s[n] = L(xn)f: image-width дэх cycle-ийн тоо · N: pixel sample-ийн тоо · φ: phase

Nyquist-ийн шаардлага (ideal band-limited сигналд): f < N/2. Жишээ нь 20 pixel-тэй image дээр 15 cycles бүхий судлыг шууд sampling хийхэд доогуур давтамжтай хуурамч хээ гарч болно.

Яагаад 15 cycles → 5 cycles болсон бэ?

20 samples-д 15 cycles нь өөр давтамжтай ижил sample утгууд үүсгэж чадна. Aliasing-ийн математик тайлбар: falias = mink∈Z |f − kN|.

Point sample vs pixel integration: Point sampling нь зөвхөн pixel-ийн төв дээрх intensity-г авна. Харин real sensor photosite нь тодорхой талбайд ирсэн гэрлийг нэгтгэдэг. Манай box average mode энэ үйлдлийн 1D approximation; өндөр frequency-ийн amplitude буурч болно. Гэхдээ энгийн box filtering бүх aliasing-ийг төгс арилгана гэсэн үг биш.

savg[n] = N ∫n/N(n+1)/N L(x) dx
cosine-ийн amplitude response = sinc(πf/N)sinc(z) = sin(z)/z. Энд normalized average хэрэглэсэн; pixel aperture-ийн frequency response үзүүлж байна.

Stereo matching-д ямар хамаатай вэ?

Баруун, зүүн камер дээрх торон болон давтагдах texture нь олон pixel location ижил төстэй харагдуулж, correspondence ambiguity үүсгэнэ. Aliasing нь feature matching-д буруу correspondence оруулж улмаар disparity, depth-г алдаатай болгоно.

03 / 08 · ANALOG → DIGITAL

Quantization: Тасралтгүй гэрлийг хэдэн түвшинд хуваадаг вэ?

Sample авсан ч intensity нь analog continuous утга байж болно. Analog-to-Digital Converter (ADC) нь үүнийг b-bit integer болгож, 2b түвшинд кодолдог. Bit depth бага байх тусам ойролцоо хоёр intensity ижил кодтой болж болно.

Qb(x) = round((2b − 1) · x) / (2b − 1),   x ∈ [0,1]
Δ = 1/(2b − 1)   ;   |e| ≤ Δ/2Энд uniform nearest-neighbor quantizer, endpoint-normalized [0,1] загвар хэрэглэв.

Яагаад энэ “resolution”-оос өөр вэ?

Spatial resolution нь pixel-ийн тоо; radiometric resolution нь нэг pixel intensity-г ялгаж кодлох түвшний тоо. 1920×1080 image 8-bit байж болно, 640×480 image 12-bit байж болно. Энэ нь гэрлийн жижиг ялгааг хэмжих чадварын өөр өөр хэмжээс юм.

Мөн raw sensor bit depth, файл дахь image format болон дэлгэцийн харуулах bit depth заавал адилхан байх албагүй. 12-bit RAW image-ийг 8-bit preview болгоход tone mapping хийж болно.

04 / 08 · PROBABILITY OF MEASUREMENT

Shot noise ба read noise: Яагаад гэрэл багатай үед зураг мууддаг вэ?

Бодит image sensor фотон хэмждэг. Ирэх фотоны тоо тогтмол биш, тодорхой статистик хэлбэлзэлтэй. Photon shot noise ихэвчлэн Poisson distribution-оор загварчлагдана. Харин read noise нь electronics, ADC уншилт зэрэгтэй холбоотой бөгөөд ойролцоогоор Gaussian гэж загварчилж болно.

Nshot ~ Poisson(μ),   E[N] = Var(N) = μ
nread ~ Normal(0, σr2)
SNR ≈ μ / √(μ + σr2)μ: expected electrons; σr: read noise (electrons RMS). Dark current, PRNU, demosaicing болон бусад хүчин зүйлсийг одоохондоо орхиод хялбарчилсан.

Photon count 4 дахин ихсэхэд shot-noise-only SNR ойролцоогоор 2 дахин сайжирна, 4 дахин биш. Учир нь noise-ийн стандарт хазайлт √μ-аар өснө.

ЯАГААД? — “Denoise” бүхнийг буцаан сэргээдэггүй

Photon sample дээр мэдээлэл хангалттай хэмжигдээгүй бол дараа нь neural denoiser ашигласан ч бодит texture-ийг баталгаатай сэргээх боломжгүй. Харин saturated pixel-ийн өндөр intensity-ийн ялгаа clipping-д бүрмөсөн алдагдана. Энэ нь exposure сонголт ба active illumination-ийн чухал trade-off.

Visual odometry connection: Feature tracking-ийн gradient жижиг, noise их үед local patch-ийн displacement uncertain болно. Дараа нь бид feature covariance, optical-flow Jacobian, image noise хэрхэн хамаарахыг Week 3-д үзнэ.

05 / 08 · CONNECT TO FOURIER AND FEATURES

Энэ бүхэн Fourier, feature extraction-тэй яаж холбогдох вэ?

Зургийн spatial frequency нь нэгж орон зайд intensity хэр хурдан өөрчлөгдөж буйг илэрхийлнэ. Удаан өөрчлөгдөх illumination нь low frequency; хурц ирмэг, нарийн хээ нь high-frequency component ихтэй байж болно.

I(x,y) = Σu Σv Cu,v · exp(i 2π (ux/W + vy/H))2D Fourier-ийн concept: зурагны pattern-ийг давтамж, amplitude болон phase-ээр илэрхийлэх. Discrete DFT-ийн normalization болон индексийг Day 4–5-д нарийвчилна.
Convolution ↔ Frequency

Spatial domain-д convolution хийх нь frequency domain-д component-үүдийг filter-ийн response-аар үржүүлэхтэй холбоотой.

Gradient ↔ Edges

Derivative нь intensity-ийн огцом өөрчлөлтийг тодруулна; noise-ийн өндөр-frequency component-үүд мөн хүчтэй болох эрсдэлтэй.

Feature ↔ Local structure

Harris/SIFT нь Fourier-ийн глобал spectrum бус, тодорхой байрлалд давтагдах боломжтой local structure хайдаг.

CNN ↔ Learned filters

CNN-ийн kernel нь target loss-оос сурсан filter; эхний layer-ийн filter заримдаа edge/texture detector-той төстэй байдаг.

Сайн мэдэх ёстой нэг ялгаа

Fourier transform нь ихэвчлэн зураг дахь frequency-ийн агуулга-ыг задалдаг. “Энэ feature зурагны яг x=220, y=140 байршилд байна” гэсэн keypoint location-ийг Fourier magnitude ганцаараа зааж өгөхгүй. Local descriptor ба frequency representation-ийг ижил гэж ойлгож болохгүй.

Дараагийн холбоос: Day 2-д convolution-ийг spatial matrix multiplication-аас эхлүүлж, frequency response хүртэл гаргана. Day 3-д derivative, Day 4–5-д Fourier-ийн complete derivation орно.

Lab 06 — Curve өөрөө high frequency гэсэн үг мөн үү?

Circle-ийн хилийн радиусыг өнцгөөс хамааран долгиолуулна: r(θ)=R+a cos(nθ). n ихсэхэд хэлбэрт олон жижиг wiggle гарч байна. Гэхдээ шулуун sharp edge ч image intensity дээр олон high-frequency component агуулж болно.

A · Smooth boundary vs wavy boundary
B · Boundary radius as function of angle θ
r(θ) = R + a cos(nθ)
n = number of wiggles / revolutionЭнэ нь contour/shape-ийн өнцгийн Fourier harmonic. Бүх 2D image-ийн Fourier спектртэй яг адил ойлголт биш.
Smooth circle

Геометрийн хэлбэр жигд; r(θ) constant. Гэхдээ хар-цагаан зураг дээр хурц circle boundary нь өөрөө өргөн 2D Fourier spectrum-тэй.

Wavy boundary

Derivation Lab — томьёо хаанаас гардаг вэ?

Доорх нотолгоонууд нь бэлэн алгоритм хэрэглэхээс өмнө ямар assumption тавьсан, аль алхамд мэдээлэл алдагдсан гэдгийг ойлгуулах зорилготой. Эхлээд өгөгдсөн асуултыг өөрөө бодоод дараа нь алхмуудыг нээж үзээрэй.

D1Continuous scene → pixel integral▾

Pixel output бол нэг coordinate дахь exact sample биш, spatial болон temporal aperture-ийн нэгтгэл байж болно:

pmn = 1/(A·T) ∫t₀t₀+T ∫∫A(m,n) E(x,y,t) dxdy dt

Дараалал: continuous irradiance E(x,y,t) → pixel aperture-ийн average → shutter хугацааны integration → electron count → quantization. Хэрэв scene/camera хөдөлж байвал temporal integral нь motion blur үүсгэнэ. Энэ шатанд алдагдсан өндөр frequency-г quantization-ийн дараа буцааж гаргаж авахгүй.

D2Aliasing formula: f ба f + kN яагаад ялгагдахгүй вэ?▾

Pixel centers xₙ=(n+1/2)/N, integer k гэж авбал:

cos[2π(f+kN)(n+1/2)/N + φ]
= cos[2πf(n+1/2)/N + φ + 2πkn + πk]
= cos[2πf(n+1/2)/N + φ + πk]

Тайлбар: 2πkn нь integer cycles учраас арилна; k odd бол phase дээр π нэмэгдэнэ. Иймээс зөв phase-ийг сонговол олон өөр continuous frequency ижил discrete sequence үүсгэх боломжтой. Undersampling-д unique reconstruction байхгүй.

D3Pixel integration → sinc MTF▾

Нэг pixel-ийн normalized interval-ийг x₀±1/(2N) гэж үзээд sine/cosine-ийн integral авна:

N∫x₀−1/(2N)x₀+1/(2N) cos(2πfx+φ) dx
= cos(2πfx₀+φ) · sin(πf/N)/(πf/N)

Тайлбар: higher spatial frequencies-ийн contrast sinc envelope-ээр багасна. Sinc нь тэг болсон frequency бүрэн арилна; negative lobes нь contrast reversal үүсгэж болно.

D4Poisson shot noise → SNR square-root law▾

N~Poisson(μ) бол E[N]=Var(N)=μ. Read noise-ийн variance σᵣ² бие даасан тул variance-ууд нийлнэ:

Signal = μ, total std = √(μ+σᵣ²)
SNR = μ / √(μ+σᵣ²)
shot-noise-only: SNR=√μ

Тайлбар: 4× photon → 2× SNR. Fixed read noise давамгай үед μ-г өсгөх нь харьцангуй илүү их тус болж болно; saturation болон хөдөлгөөний blur-ийг хамтад нь тооцно.

D5Spatial frequency ба period-ийн математик холбоо▾

64 pixel өргөнд k удаа синус давтагдана гэж үзье. Нэг cycle-ийн зайг T pixel гэвэл 64=kT, тэгэхээр T=64/k. Харин frequency нь 1 pixel бүрд ногдох cycle-ийн тоо учир f=k/64=1/T.

I[x] = 128 + A cos(2πkx/64 + φ)
k=8 → f=8/64=0.125 cycles/pixel ; T=8 pixels/cycle

k ихсэхэд cycle хоорондын зай багасдаг боловч amplitude өөрчлөгдөхгүй. Энэ нь pixel resolution-ийг нэмэгдүүлсэн гэсэн үг биш — нэг зураг дотор өөр pattern сонгож байна.

D6Brightness constancy → Optical Flow equation▾

Нэг image feature бага хугацаанд шилжихдээ brightness нь ойролцоогоор хэвээр гэж үзвэл I(x+Δx,y+Δy,t+Δt) ≈ I(x,y,t).

I(x+Δx,y+Δy,t+Δt) ≈ I + IₓΔx + IᵧΔy + IₜΔt
IₓΔx + IᵧΔy + IₜΔt ≈ 0
Δt-р хуваавал: Iₓu + Iᵧv + Iₜ ≈ 0

Энд Iₓ,Iᵧ бол нэг frame доторх орон зайн derivative, Iₜ бол цаг хугацааны derivative. u=dx/dt, v=dy/dt нь optical flow. Энэ бол бага motion, brightness constancy болон differentiability-д суурилсан first-order approximation. Aperture problem-ийг Day 15-д үзнэ.

Бодлого 1 · Aliasing

24 pixel-ээр 19 cycles/image давтамжтай pattern sample хийвэл хамгийн бага alias frequency хэд вэ? Point-sampling гэж үз.

falias = mink ∈ Z|19 − 24k| = 5 cycles/image. 19 нь Nyquist limit 12-оос их; 5 cycles-тэй signal-ийн sample sequence-тэй ялгагдахгүй байж болно (phase/sign тохируулгатай).
Бодлого 2 · Quantization

6-bit ADC-д хэдэн түвшин байдаг вэ? Normalized [0,1] загварт Δ ба max round-off error хэд вэ?

26 = 64 түвшин. Δ = 1/(64−1) ≈ 0.01587; max error = Δ/2 ≈ 0.00794 (clipping-гүй, ideal rounding).
Бодлого 3 · SNR

μ=100 e⁻, σr=5 e⁻ үед SNR хэд вэ? μ=400 e⁻ болоход хэд болох вэ? Энэ нь 4× сайн болсон гэсэн үг үү?

SNR₁ = 100/√(100+25) ≈ 8.94. SNR₂ = 400/√(400+25) ≈ 19.40. Харьцаа ≈2.17×; signal 4× өссөн ч shot noise-ийн variance signal-тай хамт өснө.
Бодлого 4 · Gaussian MTF

W=160 pixel, f=20 cycles, σ=2 pixel Gaussian PSF байвал contrast хэдэн хувь үлдэх вэ? (MTF = exp(−2π²σ²(f/W)²))

ν=20/160=0.125 cyc/pixel. MTF=exp[−2π²·(2²)·(0.125²)] = exp(−1.2337) ≈ 0.291 буюу ≈29.1%. Image blur нь тухайн frequency-ийн contrast-ийн 70.9%-ийг сулруулж байна.
Бодлого 5 · Photon energy / electrons

500 nm wavelength-ийн monochromatic light, E=0.004 W/m², pixel area 10⁻¹¹ m², t=0.01 s, QE=0.6 гэж үзвэл expected electron count хэд вэ?

Photon energy hc/λ ≈3.97×10⁻¹⁹ J. Pixel-д очих energy EAt = 0.004×10⁻¹¹×0.01 = 4×10⁻¹⁶ J; photon count ≈1007. QE=0.6 тул ≈604 e⁻. Exposure, optics, QE-ийн simplified monochromatic model гэдгийг санаарай.

64 pixel өргөнтэй зурган дээр 8 cycle байвал spatial frequency ба нэг давталтын period-ийг тооц.

f = 8/64 = 0.125 cycles/pixel. T = 1/f = 8 pixels/cycle. Нэг frame-ийн дотор x дагуу тооцсон, Hz биш.
Бодлого 7 · Motion → temporal frequency

Kernel зурагт яг юу хийдэг вэ?

02 / 08 · INDEXING MATTERS

Correlation ба convolution ижил үү?

Correlation үед kernel-ийн (i,j) coefficient-ийг image-ийн +i,+j offset-д хэрэглэнэ. Convolution үед K[−i,−j]-ийг хэрэглэнэ — өөрөөр хэлбэл coefficient-үүдийг 180° эргүүлж бодно. 1D дээр ч ижил: correlation-д k[i], convolution-д k[−i].

CORRELATION
(I ⋆ K)[m,n] = Σi,j I[m+i,n+j] K[i,j]

Template matching болон олон deep-learning framework-ийн “convolution” layer дотроо correlation үйлдэл ашигладаг. Learned kernel байвал flip-ийг weights-д шингээж сурч болно.

CONVOLUTION
(I ∗ K)[m,n] = Σi,j I[m−i,n−j] K[i,j]

Convolution нь impulse response, linear time/space invariant system болон Fourier convolution theorem-тэй байгалийн холбоотой.

Convolution яагаад kernel-ийг эргүүлдэг вэ?

Нэг pixel impulse-ийг image-ийн өөр өөр байрлалд шилжүүлэхэд output нь мөн адил шилжсэн impulse response болж гардаг. Бүх pixel-ийг тэдгээрийн impulse contribution-ийн нийлбэр гэж задлаад гаргавал Y[m]=Σ I[j] h[m−j] буюу convolution-ийн индексүүд автоматаар гарна.

Жишээ: I = [1, 2, 3], K = [1, 0, −1]. Төвийн correlation = (1)(1)+(2)(0)+(3)(−1)=−2; convolution = (1)(−1)+(2)(0)+(3)(1)=+2.
03 / 08 · LINEAR SHIFT-INVARIANT

Яагаад convolution нь linear system-ийн үндсэн хэл вэ?

Linear оператор T нь superposition биелүүлнэ: T(aI+bJ)=aT(I)+bT(J). Shift-invariant операторын хувьд input-ийг Δ pixel-ээр шилжүүлэхэд output мөн Δ-ээр шилжинэ. Эдгээр хоёр property-той discrete оператор нь тохирох нөхцөлд impulse response h-ээр convolution болж илэрхийлэгдэнэ.

I[n] = Σj I[j] δ[n−j] → T(I)[n] = Σj I[j] h[n−j] = (I∗h)[n]Эхний тэнцэтгэл: arbitrary signal бол shifted impulses-ийн нийлбэр. Хоёр дахь нь linearity. Гурав дахь нь shift invariance.

05 / 08 · SPATIAL → FREQUENCY

Kernel яагаад frequency-үүдийг тус тусад нь өөрчилдөг вэ?

y[n] = Σk h[k]x[n−k]

Gaussian kernel яагаад алдартай вэ? Separability гэж юу вэ?

2D Gaussian нь x ба y-ийн 1D Gaussian-ийн үржвэрт задрах боломжтой. Тиймээс 2D k×k filter хийхдээ шууд k² multiplication/pixel биш, эхлээд хэвтээ k, дараа нь босоо k буюу 2k multiplication/pixel ашиглаж болно. Boundary handling тогтвортой байвал математик үр дүн нь ижил.

07 / 08 · DERIVATION WORKBOOK

Томьёоны цаадах 5 математик баталгаа

01 · Нэг kernel pixel рүү яаж бууж байна?
3×3 sum-ийг дэлгэрүүлж харах

Correlation-ийн y[m,n] нь I[m−1,n−1]K[−1,−1] + I[m−1,n]K[−1,0] + ... + I[m+1,n+1]K[1,1]. Аливаа filter бол pixel-ийн 9 weighted contribution-ийн нийлбэр юм. Kernel sum=1 үед constant intensity c нь interior-т c хэвээр үлдэнэ.

02 · Linearity
Superposition-ийг бодитоор гаргах
T(aI+bJ) = (aI+bJ)∗K = a(I∗K)+b(J∗K) = aT(I)+bT(J).

Энэ algebra нь fixed kernel, input-independent coefficients нөхцөлд хүчинтэй. Median filter болон clipping бол linear биш.

03 · Convolution theorem
Complex exponential substitution
y[n]=Σkh[k]eiω(n−k)=eiωnΣkh[k]e−iωk=H(ω)eiωn

Sinusoidal component бүр eigenfunction болсноор image Fourier coefficients filter response-оор үржигддэг. Нэмэлтдээ phase shift байж болно.

04 · Gaussian-ийн separability
Exponent-ийг factorize хийе
exp[−(x²+y²)/(2σ²)] = exp[−x²/(2σ²)] · exp[−y²/(2σ²)]

Тиймээс 2D Gaussian нь rank-1 matrix болж, x/y чиглэлд салгаж тооцогдоно. 2D kernel-ийг шууд хадгалах шаардлагагүй.

05 · Filter noise variance
Weighted independent noise-д variance яагаад өөрчлөгдөх вэ?
Var(Σ kiηi) = Σ ki² Var(ηi) = σ² Σ ki²

Zero-mean, independent, equal-variance noise гэж үзвэл normalized 3×3 box filter-д 9 × (1/9)² = 1/9 variance үлдэнэ, standard deviation = σ/3. Гэхдээ edge/detail blur болно.

Хязгааруудыг сана

Linear нь заавал shift-invariant гэсэн үг биш. Boundary extension-ийг өөрчилбөл finite-domain operator-ийн shift invariance эвдэрч болно. Дурын 2D kernel Gaussian шиг separable байх албагүй.

Day 2 Knowledge Check

A. Numerical problems — 7 бодлого

Эхлээд өөрөө бод. Дараа нь бодолтын тайлбарыг нээ.

1. Input [10,20,30], box [⅓,⅓,⅓]: төвийн output?

(10+20+30)/3=20. Төвийн pixel нь average болно. Өгөгдсөн нөхцөл төвд байгаа тул boundary хамаарахгүй.

2. [1,2,3] signal, [1,0,−1] kernel: correlation vs convolution?

Correlation: −2; true convolution: +2. Kernel-ийг 180° эргүүлэхэд sign солигдоно.

3. Constant image I=100, 3×3 box. Zero padding-ийн буланд ямар output вэ?

Буланд 3×3 дотор 4 valid, 5 outside-zero байрлалтай: 4×100/9=44.44. Reflect padding үед 100 хэвээр.

4. Independent noise σ=9. 3×3 uniform average хийсний дараа σ хэд вэ?

Var_out=σ² Σ k²=81/9=9, тэгэхээр σ_out=3. White, independent noise assumption.

5. 9×9 Gaussian: direct ба separable multiplication ratio?

Direct 81, separable 9+9=18. Ratio 4.5×. Memory access болон implementation overhead-ийг тооцоогүй theoretical count.

6. Low-pass h=[¼,½,¼]. ω=π үед H(π) хэд вэ?

H(π)=¼eiπ+½+¼e−iπ=−¼+½−¼=0. Alternating pattern устна.

7. Median [1,100,2] = 2. Энэ linear filter мөн үү?

Үгүй. Order statistic буюу non-linear filtering. Median нь impulses/spikes-ийг дарж болох ч superposition property ерөнхийдөө биелэхгүй.
